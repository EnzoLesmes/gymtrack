# GymTrack

Aplicación de consola en Python para organizar rutinas de entrenamiento y registrar el progreso de los usuarios.

## Estructura inicial

- `src/main.py`: punto de entrada de la app.
- `src/database.py`: conexión y acceso a SQLite.
- `src/rutinas.py`: manejo de rutinas.
- `src/entrenamientos.py`: registro de entrenamientos.

## Requisitos

- Python 3
- SQLite incluido en la librería estándar de Python
